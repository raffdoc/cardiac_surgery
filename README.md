# cardiac_surgery

Quarto book project.

## Deployment

The book is published to GitHub Pages: [https://raffdoc.github.io/cardiac_surgery/](https://raffdoc.github.io/cardiac_surgery/)

## How to Update

To republish updates to GitHub Pages, run the following command from the `main` branch:

```bash
quarto publish gh-pages
```

This command will:
1. Render the project.
2. Push the contents of the `_book` directory to the `gh-pages` branch.
